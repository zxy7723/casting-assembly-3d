# ZG230-450 铸钢件 · 铸造工艺装配三维交互

**辽宁省大学生铸造工艺设计大赛**参赛作品的交互式三维展示件（A件-端盖）。

在线访问：**https://zxy7723.github.io/casting-assembly-3d/**

---

## 打开方式

| 方式 | 操作 |
|---|---|
| 在线（推荐） | 直接打开上面的 Pages 链接，**无需联网下载任何依赖** |
| 本地离线 | 下载 `16_铸造工艺装配三维交互.html`（6.3 MB），双击用浏览器打开 |

> 文件为**单文件自包含**：`plotly.js v4.1.1` 已完整内嵌在 `<script>` 中，双击即可离线运行。
> 唯一的外链是 6 个底图样式 JSON 与地图图标 CDN，**网络不可达时底图自动降级为纯色，三维几何与交互完全不受影响**。

## 交互操作

- **左键拖动** —— 旋转；**滚轮** —— 缩放；**右键拖动** —— 平移
- 右侧「图层控制」面板可逐项显示 / 隐藏：**铸件、分型面、上砂箱、下砂箱、浇注系统、冒口**（3 个）、**砂芯**（3 个）、**冷铁**（版 B 外冷铁建议 / 版 A 内冷铁老师原话）、**出气孔**、**砂箱型腔**、**补贴**
- 快捷按钮：**仅铸件** / **全部显示** / **全部隐藏**；视角按钮：**等轴测** / **俯视** / **仰视** / **前视**
- **双击任一部件**可单独高亮该件的名称与工艺参数

## ⚠️ 重要说明（2026-10-04 更新）

### ★ 坐标已绕 Y 轴 −90°

整件绕 **Y 轴 −90°**，即：

```
(x, y, z)  →  (−z, y, x)
```

目的是把 **X = −122 那个面**（Φ240 法兰止口前端面）**平放成水平面**，现位于 **Z = −122（下面）**；
两个大钳子（悬臂耳板）中心在 **Z = +27（上面）**，比法兰面高 149 mm。

| 项 | 旋转前 | 旋转后 |
|---|---|---|
| 包围盒 X | −147 … 83（230.000） | **±137.783（275.567）** ← 原 Z |
| 包围盒 Y | −156 … 156（312.006） | **±156（312.006）** 不变 |
| 包围盒 Z | ±137.783（275.567） | **−147 … 83（230.000）** ← 原 X |
| 对称面 | Z = 0（水平面） | **X = 0（竖直面）** |
| 耳板 | Y 91…141 | Z −27.807…+83（Y 91…141 不变） |
| 分型面 | 原 Z = 0 | **Z = −122（水平，朝下）** |

原「Z = 0 卧式」方案已**全部作废**。

### ★ 浇注系统参数（按《铸造手册 第5卷 铸造工艺》第3章推荐值）

| 组成 | 参数 |
|---|---|
| 浇口杯 | Φ76 → Φ42（杯身 Φ76） |
| 直浇道 | Φ42 |
| 横浇道 | 60 × 18，中心 **Y = −200**，底面贴分型面 |
| 内浇道 | **3 个**，各 44 × 9，X = **−70 / 0 / +70** |
| 过滤网 | **无**（铸钢件） |
| 注入方式 | **底注式**（内浇道开在分型面上） |

关键约束：内浇道厚 **h = 9.0 < 0.7 × 13 = 9.1**（书页 207「内浇道厚度应小于铸件壁厚的 0.7 倍」强约束）；
断面比 ΣA内 : ΣA横 : ΣA直 ≈ 1 : 0.93 : 1.19。

> **本页为演示 / 建模对照用**：浇注系统为示意，**冒口 / 砂芯 / 冷铁 / 补贴 / 出气孔 / 上下砂箱待补**。
